\# KANTIN BU RINA – RINA POS



\## Deskripsi Aplikasi

Kantin Bu Rina (RINA POS) merupakan aplikasi kasir berbasis website yang dibuat untuk membantu proses pengelolaan kantin, mulai dari pengelolaan barang, transaksi penjualan, hingga pemesanan makanan oleh pelanggan.



Aplikasi ini dirancang agar proses penjualan dan pengelolaan data menjadi lebih mudah, cepat, dan terorganisir.



\## Fitur Aplikasi



\### 1. Fitur Admin

\- Login dan logout admin.

\- Dashboard informasi penjualan.

\- Mengelola data barang.

\- Menambah, mengubah, dan menghapus barang.

\- Mengelola stok barang.

\- Melakukan transaksi penjualan.

\- Mencetak struk transaksi.

\- Melihat riwayat transaksi.

\- Melihat laporan penjualan.

\- Mengelola pesanan pelanggan.

\- Mengubah status pesanan.

\- Notifikasi pesanan baru.



\### 2. Fitur Pelanggan

\- Melihat daftar menu makanan dan minuman.

\- Melihat harga dan gambar produk.

\- Menambahkan produk ke keranjang.

\- Mengubah jumlah pesanan.

\- Melakukan checkout.

\- Mengisi identitas dan alamat pemesanan.

\- Mengecek status pesanan.

\- Mencetak bukti pesanan.



\## Teknologi yang Digunakan

\- XAMPP

\- Git dan GitHub



\## Cara Menjalankan Aplikasi



1\. Install dan jalankan XAMPP.

2\. Aktifkan Apache dan MySQL.

3\. Salin folder `kasir\_bu\_rina` ke dalam folder `htdocs`.

4\. Buka phpMyAdmin melalui browser.

5\. Buat database dengan nama `db\_kasir\_burina`.

6\. Import file `db\_kasir\_burina.sql`.

7\. Periksa konfigurasi database pada `config/koneksi.php`.

8\. Pastikan konfigurasi port MySQL sesuai dengan XAMPP yang digunakan.

9\. Buka aplikasi melalui browser:



`http://localhost/kasir\_bu\_rina/`



\## Struktur Folder



\- `assets/` – File CSS dan JavaScript.

\- `config/` – Konfigurasi koneksi database.

\- `pages/` – Halaman pengelolaan admin.

\- `pelanggan/` – Halaman pemesanan pelanggan.

\- `uploads/` – Penyimpanan gambar barang.

\- `beranda.php` – Halaman utama.

\- `index.php` – Dashboard admin.

\- `login.php` – Halaman login admin.

\- `db\_kasir\_burina.sql` – Struktur database aplikasi.



\## Database

Nama database: `db\_kasir\_burina`



File database tersedia pada repository ini dengan nama `db\_kasir\_burina.sql`.
